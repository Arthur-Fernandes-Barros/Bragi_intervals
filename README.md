# 🎵 Bragi_intervals

**Bragi_intervals** é uma ferramenta simples e eficiente construída com **Python** e **Streamlit** para músicos e estudantes de teoria musical. O objetivo do aplicativo é gerar instantaneamente o campo harmônico (maior, menor e relativo menor) de qualquer nota escolhida, exibindo os intervalos correspondentes em numerais romanos.

O nome é inspirado em **Bragi**, o deus da poesia e da música na mitologia nórdica.

## 🚀 Funcionalidades

* **Campo Harmônico Maior:** Gera a sequência de acordes baseada na escala maior.
* **Campo Harmônico Menor:** Exibe a estrutura da escala menor natural.
* **Relativo Menor:** Identifica e projeta o campo harmônico da relativa menor da nota selecionada.
* **Visualização de Intervalos:** Identificação clara dos graus (I, II, III, IV, V, VI, VII).

## 🛠️ Tecnologias Utilizadas

* [Python](https://www.python.org/): Linguagem base do projeto.
* [Streamlit](https://streamlit.io/): Framework utilizado para a criação da interface web interativa.

## 📋 Como Executar o Projeto

Para rodar o Bragi_intervals localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/seu-usuario/bragi-intervals.git
    cd bragi-intervals
    ```

2.  **Instale as dependências:**
    Certifique-se de ter o Python instalado e execute:
    ```bash
    pip install streamlit
    ```

3.  **Inicie o aplicativo:**
    ```bash
    streamlit run main.py
    ```

## 📸 Interface

O aplicativo apresenta uma interface limpa onde o usuário seleciona uma nota tônica através de um menu dropdown e recebe os campos harmônicos formatados em blocos informativos.
